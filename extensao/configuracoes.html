A extensão usa a API do Google Gemini. Crie uma chave no Google AI Studio e salve-a aqui.

Como seus dados são usados

A chave fica no armazenamento local desta extensão neste navegador. O diff e a chave são enviados diretamente à API do Google para análise. A extensão não tem servidor próprio e não salva os diffs. Evite enviar código confidencial e consulte os termos do provedor. Remova a chave antes de compartilhar seu perfil do navegador.
